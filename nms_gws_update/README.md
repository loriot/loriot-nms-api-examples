# LORIOT Network Management System: Update loriot gw bin

This software is an example implementation of the loriot.io NMS API.

Official documentation links:
- [NMS API](https://docs.loriot.io/space/NMS/439451649/API+Documentation)
- [LORIOT Gateway Binary](https://docs.loriot.io/space/NMS/6036241/LORIOT+Gateway+Binary)


## Disclaimer

Software is delivered with no guaranty. It is only an example of implementation.

## Usage

```bash
python main.py --server <server> --user <username> --password <password>
```

## Parameters

- `--server`: Target loriot server address
- `--user`: Username for authentication
- `--password`: Password for authentication
